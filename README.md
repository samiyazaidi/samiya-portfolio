# Samiya — Editorial Developer Portfolio

A warm blush-and-burgundy developer portfolio built with React, TypeScript, Vite, Tailwind CSS v4, Framer Motion, Lucide React and React Icons.

## Start locally

Use Node.js 22.12 or newer.

```bash
npm ci
npm run dev
```

See [SETUP.txt](./SETUP.txt) for the layout, content data files, CV setup, contact form delivery, and deployment instructions.

## Layout

The original hero is preserved. Below it are What I Do + About Me, a compact project carousel, a horizontal skill rail, then work/education timelines beside a contact form, followed by the footer. The approved visual reference is in `docs/approved-layout-reference.png`; it is not loaded into the live page.
